# Group Project — MEBEL

A calm, minimalist furniture storefront built by a three-person team for the
Web Programming group project.

## Live site

- Explainer page: https://olimjonovziyodulloh-coder.github.io/group-project/
- Store app: https://olimjonovziyodulloh-coder.github.io/group-project/mebel.html

## What it does

- Browse and search a furniture catalogue by category
- Product detail view with gallery and related pieces
- Wishlist (saved pieces) and shopping cart with currency switching
- Weather-based picks for a chosen city
- Room planner from a room size
- Style quiz to narrow the catalogue
- Day / evening theme toggle

## Stack

React 18 (UMD), Tailwind CSS (CDN), Babel Standalone, localStorage, no build
step, deployed to GitHub Pages.
