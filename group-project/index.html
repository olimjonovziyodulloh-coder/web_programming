The idea

Why we built it

Furniture shopping is usually loud and overwhelming. MEBEL is a small storefront with a calm, Scandinavian / Japandi feel: a clean catalogue, honest product details and tools that help you decide, not just buy.

What you can do

Features of the store

Browse & search

Filter by category, search by name and sort the catalogue. Each card shows price, rating and stock.

Product details

Image gallery, description, materials and a "complete the sanctuary" set of related pieces.

Wishlist

Save pieces you love and come back to them later; the list persists between visits.

Shopping cart

Add items, change quantities and switch currency. Totals update live.

Weather picks

Choose a city and get furniture suggestions that fit the day's weather.

Room planner

Enter a room size and get pieces sized and styled for that space.

Style quiz

A short quiz that narrows the catalogue to the style that fits you.

Day / evening mode

Swap the whole palette for a warmer evening look, saved as a preference.

How it is built

Stack and approach

  • React 18 (UMD)
  • Tailwind CSS (CDN)
  • Babel Standalone
  • localStorage
  • No build step
  • GitHub Pages

Everything runs in the browser: the catalogue, cart, wishlist and preferences live in React state and localStorage, so there is no backend and no database. The page is a single HTML file that loads React, Tailwind and Babel from CDNs, which keeps deployment to GitHub Pages a simple file upload.

What we learned

Takeaways from building it

  • Component composition: splitting the store into small pieces (cards, details, cart, planner) made the state easy to reason about.
  • Persistence pays off: keeping cart, wishlist and theme in localStorage makes the app feel like a real product.
  • Design is a feature: a calm palette and generous spacing changed how usable the catalogue felt.
  • No backend, no problem: mock data and client-side state are enough to demo a full flow.
