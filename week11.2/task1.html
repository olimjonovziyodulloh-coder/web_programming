Seven exercises

React state & events

Each demo is a small React 18 component mounted on this page. Open View React example to read the code behind it.

E1

Update state with a counter

Each click uses the previous value, so fast repeated clicks still add up correctly.

View React example 
const [count, setCount] = useState(0);

<button onClick={() => setCount((value) => value + 1)}>
  Add one
</button>
E2

Keep an input in sync

The input's value lives in state, and the greeting updates on every keystroke.

View React example 
const [name, setName] = useState('');

<input
  value={name}
  onChange={(event) => setName(event.target.value)}
/>
<p>Hello, {name.trim() || 'there'}!</p>
E3

Add and remove list items

Arrays are updated immutably, every task gets a stable id, and the input clears after adding.

View React example 
const [tasks, setTasks] = useState(initialTasks);
const [draft, setDraft] = useState('');

function addTask(event) {
  event.preventDefault();
  if (!draft.trim()) return;

  setTasks((current) => [
    ...current,
    { id: nextId.current++, title: draft.trim() },
  ]);
  setDraft('');
}

function removeTask(id) {
  setTasks((current) => current.filter((task) => task.id !== id));
}
E4

Show and hide content

A boolean controls the panel, and aria-expanded tells assistive technology whether it is open.

View React example 
const [open, setOpen] = useState(false);

<button
  aria-expanded={open}
  aria-controls="extra-details"
  onClick={() => setOpen((value) => !value)}
>
  {open ? 'Hide details' : 'Show details'}
</button>
<div id="extra-details" hidden={!open}>
  {open && <p>More information goes here.</p>}
</div>
E5

Complete and filter tasks

Tasks are updated immutably, then filtered by status with a second piece of state.

View React example 
function toggleTask(id) {
  setTasks((current) =>
    current.map((task) =>
      task.id === id ? { ...task, completed: !task.completed } : task
    )
  );
}

const visible = tasks.filter((task) => {
  if (filter === 'active') return !task.completed;
  if (filter === 'done') return task.completed;
  return true;
});
E6

Validate a controlled form

Both fields share one state object, and the message appears only after the form is submitted.

View React example 
const [profile, setProfile] = useState({ name: '', email: '' });
const [message, setMessage] = useState('');

function updateField(event) {
  const { name, value } = event.target;
  setProfile((current) => ({ ...current, [name]: value }));
}

function saveProfile(event) {
  event.preventDefault();
  if (!profile.name.trim() || !profile.email.trim()) {
    setMessage('Add both a name and an email.');
    return;
  }
  setMessage(`Saved ${profile.name.trim()}'s profile.`);
}
E7

Save a note in the browser

An effect writes the note to localStorage after every change, so it survives a reload.

View React example 
const [note, setNote] = useState(
  () => localStorage.getItem('week11-note') || ''
);

useEffect(() => {
  localStorage.setItem('week11-note', note);
}, [note]);
